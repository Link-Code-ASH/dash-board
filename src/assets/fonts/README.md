# HUB typography

Self-hosted WOFF2 assets. Mindfold retains its existing typeface.

- Pretendard Variable v1.3.9: https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard/dist/web/variable/woff2
- IBM Plex Sans KR Medium and SemiBold: https://github.com/IBM/plex/tree/master/packages/plex-sans-kr/fonts/complete/woff2/hinted

Both families use the SIL Open Font License. Original license files are included alongside the fonts.
